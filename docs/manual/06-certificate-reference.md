# 6 Certificate editor reference

> [Deutsch](06-certificate-reference.de.md) · **English**

Reference for placeholders, fonts, dimensions, keyboard shortcuts and limits.

## Placeholders

Placeholders stand in double curly braces in a text. They are replaced when the certificate is
generated. Each placeholder may occur several times and in any text block.

| Placeholder | Replaced by | Example in the page view |
|---|---|---|
| `{{GIVEN_NAME}}` | Given name of the participant | Max |
| `{{FAMILY_NAME}}` | Family name | Mustermann |
| `{{EVENT_NAME}}` | Name of the event | Beispiel-OL |
| `{{RESULT_POSITION}}` | Position | 1 |
| `{{CATEGORY}}` | Short name of the category | H35- |
| `{{RESULT_TIME}}` | Running time; `mm:ss`, from one hour `HH:mm:ss` | 32:14 |
| `{{ORGANISATION}}` | Name of the club | Kaulsdorfer OLV Berlin |

If the participant has no club or no time, the placeholder remains unchanged in the text.
The source is `TextBlockProcessor` in the backend.

## Fonts

The font names in the layout are those of the PDF library.

| Family | Normal | Bold | Italic | Bold italic |
|---|---|---|---|---|
| Helvetica | `Helvetica` | `Helvetica-Bold` | `Helvetica-Oblique` | `Helvetica-BoldOblique` |
| Times | `Times-Roman` | `Times-Bold` | `Times-Italic` | `Times-BoldItalic` |
| Courier | `Courier` | `Courier-Bold` | `Courier-Oblique` | `Courier-BoldOblique` |
| Amaranth | `Amaranth-Regular.ttf` | `Amaranth-Bold.ttf` | `Amaranth-Italic.ttf` | `Amaranth-BoldItalic.ttf` |
| Montserrat | `Montserrat-Regular.ttf` | `Montserrat-Bold.ttf` | `Montserrat-Italic.ttf` | `Montserrat-BoldItalic.ttf` |
| Satisfy | `Satisfy-Regular.ttf` | none | none | none |
| Tangerine | `Tangerine-Regular.ttf` | none | none | none |
| Symbol | `Symbol` | none | none | none |
| Zapf Dingbats | `ZapfDingbats` | none | none | none |

- Without a specification, the PDF uses Helvetica.
- The choice of a font for a block takes precedence over the document fonts. If the block has none,
  the matching document font applies for bold, italic or both, otherwise the document font
  **Font**.
- If there is no font for a style, the PDF output **fakes** bold (outline) and italic
  (slant of about 12°). The width of the letters does not change.
- More fonts can be added, see
  [`doc/itext-font-integration-guide-generic.md`](../../doc/itext-font-integration-guide-generic.md).
  The licences of the bundled fonts (Amaranth, Montserrat and Tangerine under the SIL Open
  Font License 1.1, Satisfy under Apache 2.0) are in
  [`frontend/src/features/certificate/assets/fonts`](../../frontend/src/features/certificate/assets/fonts/README.md).

## Dimensions and default values

| Size | Value |
|---|---|
| Page | A4, 595 × 842 pt |
| Page margins without `document` | 36 pt on all sides |
| Page margins with `document`, without a specification | top 30, bottom 30, left 20, right 20 pt |
| Spacing above and below a paragraph | 4 pt (a value of your own replaces it) |
| Default tab stop without a specification | 261.5 pt, centred |
| Grid after the last tab stop | Multiples of 50 pt |
| Font size without a specification | 12 pt |
| Image width without a specification | 100 pt |
| Line height | Factor times font size, depending on the font (see below) |

The **line height** depends on the font. It was measured on PDFs generated by the backend:

| Font | Line height | Baseline |
|---|---|---|
| Helvetica (default) | 1.499 | 1.056 |
| Times | 1.458 | 1.009 |
| Courier | 1.273 | 0.92 |
| Amaranth | 1.964 | 1.426 |
| Montserrat | 2.108 | 1.382 |
| Satisfy | 1.921 | 1.183 |
| Tangerine | 1.45 (estimated) | 0.949 |

Both values are factors of the font size. The baseline is the distance from the top edge
of the line to the font baseline. An image stands with its bottom edge on this line.

## Keyboard shortcuts in the graphic editor

| Key | Effect |
|---|---|
| Click | Select a block |
| Shift+click | Add a block to the selection or remove it |
| Draw a frame on an empty page | Select touched blocks (with Shift: add) |
| Drag | Move a block (vertically or horizontally, depending on the direction) |
| Alt while dragging | Everything below moves along |
| Double-click on text | Edit the text |
| Double-click on an image | Choose another image |
| Enter | Edit the selected text, accept while editing |
| Esc | Cancel editing |
| Arrow keys | Move the block by 1 pt |
| Shift+arrow keys | Move the block by 10 pt |
| Alt+arrow keys | Like arrow keys, but everything below moves along |
| Delete, Backspace | Delete the selected blocks |
| Ctrl+Z (Cmd+Z) | Undo |
| Ctrl+Y (Cmd+Y), Shift+Ctrl+Z | Redo |

## Limits of the page view

The page view in the graphic editor recalculates the layout the way the backend sets it. The
dimensions come from measurements on real PDFs of 13 certificates. Deviations remain:

- **Vertical:** up to about 1 pt.
- **Left edge** of a block: up to about 3 pt.
- **Width** of a text: up to about 5 pt. For bold Amaranth and Montserrat lines, the
  deviation is around 2 %, the cause is not clarified.
- **Tangerine:** The line height is only estimated, because in the measured certificates it
  occurred only in a last line.
- **Line breaks** of long texts and **page breaks** are not displayed.
- The images appear with their real aspect ratio. The height of an image in the PDF results
  from width times ratio.
- The page view has so far been checked in the Chromium browser. Firefox and Safari are not tested.

The [PDF preview](02-certificates.md#the-preview) remains authoritative. The decision behind it is in
[ADR 0013](../adr/0013-certificate-geometry-from-pdf-measurements.md).
