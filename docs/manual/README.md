# Resulter User Manual

> [Deutsch](README.de.md) · **English**

This manual describes how to use Resulter, the web application for orienteering results. It is
being written step by step. So far, only the **certificate editor** with its three variants is
fully documented. The other chapters exist as an outline and will be added later.

**As of:** 27.11.2026. The certificate editor is described as it works in the browser after the
corrections from the test (source code after version 4.12.3, see
[Status and limits](#status-and-limits)).

## How the manual is organised

- Each chapter is a separate file, and the number sets the order.
- Images are in the folder [`images`](images/) in WebP format.
- The images show a sample certificate with sample data (Max Mustermann). They were taken with the
  application in the browser.
- Controls are set in **bold**, as they are labelled in the application
  (for example **Add text**).
- "Point" (pt) is the unit of measurement of the page. An A4 page is 595 × 842 pt.

## Status and limits

- The editor images come from a browser test with a development server whose interface was
  replaced by fixed sample data. The PDF preview in the images, however, was generated by the real
  application.
- The manual describes what the application does. Where a function has not yet been tried in
  practice, the respective chapter says so.
- It still has to be clarified how certificates are offered to participants for download
  (chapter 7). The manual only describes here what can be verified in the source code.
